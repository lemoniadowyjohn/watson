# Representative Power Fx patterns

These snippets document intended canvas-app behavior for a personal/developer environment. They are not exports from an employer tenant.

## Submit-button validation

```powerfx
If(
    IsBlank(txtTitle.Text) ||
    IsBlank(cmbComponent.Selected) ||
    IsBlank(cmbSeverity.Selected),
    Notify("Complete the required fields.", NotificationType.Error),
    SubmitForm(frmIssue)
)
```

## Search/filter gallery

```powerfx
Filter(
    Issues,
    IsBlank(txtSearch.Text) ||
        StartsWith(Title, txtSearch.Text),
    IsBlank(cmbStatusFilter.Selected.Value) ||
        Status = cmbStatusFilter.Selected.Value
)
```

## Editable-state rule

```powerfx
If(
    ThisItem.Status in ["Draft", "Rejected"],
    DisplayMode.Edit,
    DisplayMode.View
)
```

Final field identifiers should be generated by the target Dataverse environment rather than copied from this documentation.
