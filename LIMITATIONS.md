# Limitations

This repository is a solution-design portfolio artifact, not a tenant export or production deployment.

- The Power Fx snippets are representative patterns, not generated identifiers from a live Dataverse environment.
- The approval flow is documented as a design rather than exported as a deployable solution package.
- The UI visual is a conceptual wireframe, not an application screenshot.
- Environment variables, connection references and security roles are documented but not bound to a live tenant.
- No performance, adoption or business-impact metrics are claimed for this portfolio implementation.

The supporting-project classification is intentional so the evidence remains technically honest.
