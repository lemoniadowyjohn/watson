# Industrial Automation & Quality Portfolio

This repository serves as a public-safe portfolio container. Historical Watson coursework is preserved on the `legacy-watson-coursework` branch.

## Recruiter-facing projects

### Python / Excel Data Reconciliation Demo
[Open project](portfolio/python-excel-data-reconciliation-demo)

Synthetic CSV/XLSX reconciliation with deterministic business keys, validation, reason-coded discrepancies, reviewable exception output, OpenPyXL workbook generation, automated tests and CI.

### Quality Issue & Inspection Management App
[Open Power Platform reference implementation](portfolio/power-platform-quality-app)

Public-safe Power Platform architecture/reference implementation covering Power Apps patterns, Dataverse schema, Power Automate approval design, SharePoint evidence storage, governance/ALM concepts and synthetic sample data.

## Evidence boundary

These are sanitized portfolio implementations. They do not expose employer/customer data and do not convert project evidence into unsupported claims of enterprise platform ownership.

The Power Platform app remains a **reference implementation** until instantiated in a real personal/developer tenant. The Python/Excel reconciliation demo is executable public portfolio evidence and uses synthetic data.
